# CleanDesk AI V2

由 Codex 制作

CleanDesk AI 是一款 Windows 优先、完全本地运行的数字空间管理器。它帮助你看清桌面与文件夹里的文件状态，在每次操作前生成清晰预览；不会自动删除文件，也不会把文件内容或路径上传到网络。

## V2 更新内容

- 新增 **文件生命周期**：按近期活跃、待整理、建议归档、人工复核展示文件所处阶段，帮助你决定下一步，而不是替你擅自移动文件。
- 新增 **本地 AI 文件理解**：可接入 Ollama，在电脑本机为文件生成摘要、标签、分类与整理建议。
- 新增 **工作空间与零文件专注模式**：进入专注模式后桌面保持清爽；打开工作空间会以应用内浮层展示，关闭后会返回专注桌面。
- 分类列表支持展开/折叠，按文档、图片、视频、音频、安装包、压缩包等类型查看结果。
- AI 建议可直接转为“预览整理”或“预览归档”；实际移动仍需要你在预览页勾选并确认。
- 改进整理历史：记录具体整理了哪些文件、从哪里移动到哪里，并支持一键撤销。

## 主要能力

- 扫描 Windows 桌面或你手动选择的目录。
- 用明确规则划分待整理、建议归档、需保留、重复/相似文件。
- 用 SHA-256 检测完全重复文件；相似文件仅供查看与比较，绝不自动处理。
- 按文件类型生成整理目标；出现同名文件时安全追加序号，不覆盖原文件。
- 本地 SQLite 保存配置、扫描快照与整理历史，可撤销已执行的移动操作。

## 本地 AI（Ollama）使用指南

V2 的 AI 是可选功能。没有安装 Ollama 时，CleanDesk 仍然可以使用基础扫描、分类、预览、整理和撤销功能。安装 Ollama 后，模型也只在你的电脑上运行；CleanDesk 不会上传文件内容。

### 1. 安装 Ollama

从 [Ollama Windows 下载页](https://ollama.com/download/windows) 下载并安装。安装完成后，Ollama 会在本机提供服务，默认地址为：

```text
http://127.0.0.1:11434
```

### 2. 可选：把模型保存到 E 盘或其他磁盘

在 PowerShell 中执行一次以下命令（把路径改成你希望使用的位置）：

```powershell
[Environment]::SetEnvironmentVariable("OLLAMA_MODELS", "E:\OllamaModels", "User")
```

随后完全退出 Ollama 并重新打开它，再下载模型。已有模型不会自动搬迁；如需迁移，请重新下载到新目录。

### 3. 下载模型

推荐先下载平衡速度和理解能力的模型：

```powershell
ollama pull qwen2.5:1.5b
```

下载后可用下面的命令确认模型已经可用：

```powershell
ollama list
```

### 4. 在 CleanDesk 中连接

打开 CleanDesk 的“设置”或 AI 设置区域，选择“完全本地模式”，启用本地模型，并填写：

- Ollama 地址：`http://127.0.0.1:11434`
- 模型名称：例如 `qwen2.5:1.5b`

保存后，在文件列表中使用“理解文件”。AI 会给出摘要、标签和建议动作。建议动作只是建议：所有移动、归档都必须经过你的预览与确认。

### 模型推荐

| 模型 | 适合场景 | 说明 |
| --- | --- | --- |
| `qwen2.5:0.5b` | 配置较低的电脑、基础标签 | 占用最小，理解能力较基础。 |
| `qwen2.5:1.5b` | 大多数用户 | **V2 推荐**，速度、内存占用与中文理解较均衡，约 1 GB。 |
| `qwen2.5:3b` | 希望得到更细致的摘要 | 理解更好，需要更多内存与约 2 GB 模型空间。 |

V2 不建议为了文件整理使用 7B 及以上模型：它们启动更慢、硬件占用更高，而对文件分类和标签的提升通常有限。

> CleanDesk 安装包不会捆绑 Ollama 或模型，以保证安装包轻量、模型版本由用户自己选择。普通用户无需安装 Node.js 或 Rust；只有需要本地 AI 时，才需另行安装 Ollama 与一个模型。

## 安装与使用

前往本仓库的 [Releases](https://github.com/chashaopingguopai/CleanDesk-AI-/releases) 页面，下载 `CleanDesk_2.0.0_x64-setup.exe` 并运行安装。安装后直接从开始菜单打开 CleanDesk。

首次使用时，选择要扫描的目录（默认是桌面），查看扫描结果与整理预览，确认后才会移动文件。任何已执行的移动都可以在“整理历史”中撤销。

## 本地开发

开发环境需要 Node.js 20+、Rust stable 与 Windows WebView2。

```powershell
npm install
npm.cmd run tauri dev
```

构建安装包：

```powershell
npm.cmd run tauri build
```

所有扫描快照、配置和操作记录保存在 Windows 本地应用数据目录的 `CleanDesk/cleandesk.db` 中。

## 安全边界

- 不提供自动删除、云同步或后台定时扫描。
- 不扫描系统隐藏目录。
- 重复/相似文件只用于提示，由用户自行决定处理方式。
- AI 始终运行在本地 Ollama，且只提供可解释建议，不会绕过确认流程。
